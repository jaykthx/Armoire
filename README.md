### Armoire
GUI for adjusting various databases for a certain game series.
 
# Dependencies
- NET 8 Runtime [The program will not run if this is not installed!]
- Skyth's MikuMikuLibrary

# Requirements
- Windows 10 or higher (64-bit)

# Updates (16/12/2025)
- Added optional support for the 'Future Tone Customization' mod, allowing users to add 2 preview images
- Reorganised the item type picking dialog to match the original sorting method
